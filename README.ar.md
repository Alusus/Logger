# مـسجل (Logger)

<div dir=rtl>

[[English]](README.md)

مكتبة تسجيل للغة الأسس. تكتب كل سجل في سطر واحد بصيغة `logfmt`، وهي قائمة من أزواج `مفتاح=قيمة`:

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00 level=info message="logged in" user=hisham age=22
```

</div>

يبدأ كل سجل بثلاثة مفاتيح:

* `time`: وقت كتابة السجل، بصيغة RFC 3339.
* `level`: مستوى السجل: `error` أو `warning` أو `info` أو `debug`.
* `message`: رسالة السجل.

وبعدها تأتي [الخصائص العامة](#الخصائص-العامة) للمسجل، ثم الخصائص التي تضيفها للسجل بنفس ترتيب إضافتها.

تبقى أسماء المفاتيح `time` و`level` و`message` بالإنجليزية في المخرجات حتى عند استخدام الأسماء العربية، كي
تستطيع أدوات قراءة السجلات فهم السطر بنفس الطريقة أيًا كانت لغة الشيفرة.

## إضافة المكتبة للمشروع

اشمل المكتبة في مشروعك كالتالي:

```
اشمل "مـحا"؛
مـحا.اشمل_حزمة("Alusus/Logger@0.1"، "مـسجل")؛
```

<div dir=ltr>

```
import "Apm";
Apm.importPackage("Alusus/Logger@0.1");
```

</div>

## طريقة الاستخدام

أنشئ كائنًا من `مـسجل`، ثم سجّل عبر ماكروات المستويات: `خطأ` و`تحذير` و`معلومات` و`تنقيح`. يستقبل كل ماكرو رسالة،
وخصائص السجل اختياريًا:

```
عرف سجل: مـسجل؛
سجل.معلومات["تسجيل دخول"، { المستخدم: "هشام"، العمر: 22، مدير: 1 }]؛
```

<div dir=ltr>

```
def logger: Logger;
logger.info["logged in", { user: "hisham", age: 22, admin: true }];
```

```
time=2026-10-05T11:40:48+00:00 level=info message="logged in" user=hisham age=22 admin=true
```

</div>

يُطبع السجل فورًا. السجلات التي مستواها أدنى من [مستوى التسجيل](#مستوى_التسجيل-loglevel) تُهمل.

لكل كائن `مـسجل` إعداداته الخاصة (المستوى والمنطقة الزمنية والخصائص العامة).

### الخصائص

يمكن كتابة وسيط الخصائص بأي من الصيغ التالية:

```
سجل.معلومات["رسالة"، { أ: 1، ب: "نص" }]؛   // أقواس معقوفة
سجل.معلومات["رسالة"، (أ: 1، ب: "نص")]؛     // أقواس دائرية
سجل.معلومات["رسالة"، أ: 1]؛                 // خاصية واحدة
```

المفتاح إما معرّف أو سلسلة نصية (مثل `"مفتاحي"`)، وأي شيء آخر (مثل `1: س`) يسبب خطأ في الترجمة. أنواع القيم المدعومة:

* النصوص (`مؤشر[مصفوفة[مـحرف]]`).
* الأعداد الصحيحة (`صـحيح[64]`)، وتُطبع كما هي.
* الأعداد العائمة (`عـائم[64]`)، وتُطبع بست خانات عشرية، فتُطبع `0.5` هكذا `0.500000`.
* القيم الثنائية (`ثـنائي`)، وتُطبع `true` أو `false`. لاحظ أن القيمتين الحرفيتين `1` و`0` تُطابقان `ثـنائي` وليس العدد الصحيح.
* كائنات الخطأ (`خـطأ`)، وتضيف خاصيتين: `<مفتاح>.code` و`<مفتاح>.msg`.

```
عرف خ: سـندنا[خـطأ_عام] = خـطأ_عام.أنشئ("E100"، "حدث خطأ ما")؛
سجل.خطأ["فشل"، (error: خ، إضافي: "قيمة")]؛
```

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00 level=error message=فشل error.code=E100 error.msg="حدث خطأ ما" إضافي=قيمة
```

</div>

### الخصائص العامة

تُضاف الخصائص العامة إلى كل سجل يكتبه المسجل بعد إضافتها. تُضاف باستخدام `حدد`، إما كاستدعاء دالة لخاصية واحدة، أو
كماكرو يقبل نفس صيغ خصائص السجل:

```
سجل.حدد("الخدمة"، "فوترة")؛
سجل.حدد[المنفذ: 8080]؛
سجل.حدد[{ المنطقة: "eu"، النسخ: 3 }]؛

سجل.معلومات["بدأ التشغيل"]؛
```

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00 level=info message="بدأ التشغيل" الخدمة=فوترة المنفذ=8080 المنطقة=eu النسخ=3
```

</div>

إضافة نفس المفتاح مرتين تضيفه مرتين. لحذف كل الخصائص العامة استدع `فرغ`:

```
سجل.فرغ()؛
```

## مـسجل (Logger)

```
صنف مـسجل {
    عرف مـستوى: { خـطأ، تـحذير، مـعلومات، تـنقيح }
    عرف استخدم_الوقت_المحلي: ثـنائي؛
    عملية هذا.مستوى_التسجيل: صـحيح؛
    عملية هذا.مستوى_التسجيل = صـحيح؛
    دالة اسم_المستوى(مستوى: صـحيح): مـؤشر_محارف؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: مـؤشر_محارف)؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: صـحيح[64])؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: عـائم[64])؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: ثـنائي)؛
    ماكرو حدد[هذا، خصائص]؛
    عملية هذا.فرغ()؛
    ماكرو خطأ[هذا، رسالة] / خطأ[هذا، رسالة، خصائص]؛
    ماكرو تحذير[هذا، رسالة] / تحذير[هذا، رسالة، خصائص]؛
    ماكرو معلومات[هذا، رسالة] / معلومات[هذا، رسالة، خصائص]؛
    ماكرو تنقيح[هذا، رسالة] / تنقيح[هذا، رسالة، خصائص]؛
}
```

<div dir=ltr>

```
class Logger {
    def Level: { ERROR, WARNING, INFO, DEBUG }
    def useLocalTime: Bool;
    handler this.logLevel: Int;
    handler this.logLevel = Int;
    func levelName(level: Int): CharsPtr;
    handler this.set(key: CharsPtr, val: CharsPtr);
    handler this.set(key: CharsPtr, val: Int[64]);
    handler this.set(key: CharsPtr, val: Float[64]);
    handler this.set(key: CharsPtr, val: Bool);
    macro set[this, props];
    handler this.clear();
    macro error[this, msg] / error[this, msg, props];
    macro warning[this, msg] / warning[this, msg, props];
    macro info[this, msg] / info[this, msg, props];
    macro debug[this, msg] / debug[this, msg, props];
}
```

</div>

### مـستوى (Level)

```
عرف مـستوى: {
    عرف خـطأ: 40؛
    عرف تـحذير: 30؛
    عرف مـعلومات: 20؛
    عرف تـنقيح: 10؛
}
```

<div dir=ltr>

```
def Level: {
    def ERROR: 40;
    def WARNING: 30;
    def INFO: 20;
    def DEBUG: 10;
}
```

</div>

مستويات السجل مرتبة من الأهم إلى الأقل أهمية. تُستخدم مع `مستوى_التسجيل`.

### مستوى_التسجيل (logLevel)

```
عملية هذا.مستوى_التسجيل: صـحيح؛
عملية هذا.مستوى_التسجيل = صـحيح؛
```

<div dir=ltr>

```
handler this.logLevel: Int;
handler this.logLevel = Int;
```

</div>

أدنى مستوى يُطبع. السجلات التي مستواها أدنى من ذلك تُهمل. القيمة الافتراضية هي `مـستوى.مـعلومات` (`Level.INFO`).
إسناد قيمة ليست من قيم [مـستوى](#مـستوى-level) يُتجاهل ويبقى المستوى الحالي كما هو.

```
سجل.مستوى_التسجيل = مـسجل.مـستوى.تـحذير؛
سجل.معلومات["لن يطبع"]؛
سجل.تحذير["سيطبع"]؛
```

### استخدم_الوقت_المحلي (useLocalTime)

```
عرف استخدم_الوقت_المحلي: ثـنائي؛
```

<div dir=ltr>

```
def useLocalTime: Bool;
```

</div>

تحدد المنطقة الزمنية للمفتاح `time`. ينطبق على كل سجل يُكتب بعد تغييره. إذا كانت `1` يُطبع الوقت بالتوقيت المحلي
مع فرق التوقيت الخاص به. وإذا كانت `0` (الافتراضي) يُطبع بالتوقيت العالمي UTC مع فرق التوقيت `+00:00`.

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00     // UTC (default)
time=2026-10-05T14:40:48+03:00     // local time
```

</div>

### اسم_المستوى (levelName)

```
دالة اسم_المستوى(مستوى: صـحيح): مـؤشر_محارف؛
```

<div dir=ltr>

```
func levelName(level: Int): CharsPtr;
```

</div>

ترجع اسم المستوى كما يُطبع في المفتاح `level`: `error` أو `warning` أو `info` أو `debug`.

### حدد (set)

```
عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: مـؤشر_محارف)؛
عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: صـحيح[64])؛
عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: عـائم[64])؛
عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: ثـنائي)؛
ماكرو حدد[هذا، خصائص]؛
```

<div dir=ltr>

```
handler this.set(key: CharsPtr, val: CharsPtr);
handler this.set(key: CharsPtr, val: Int[64]);
handler this.set(key: CharsPtr, val: Float[64]);
handler this.set(key: CharsPtr, val: Bool);
macro set[this, props];
```

</div>

تضيف [خاصية عامة](#الخصائص-العامة). راجع [المفاتيح](#المفاتيح) و[القيم](#القيم) لمعرفة كيفية طباعتها.

### فرغ (clear)

```
عملية هذا.فرغ()؛
```

<div dir=ltr>

```
handler this.clear();
```

</div>

تحذف كل [الخصائص العامة](#الخصائص-العامة) المضافة بـ`حدد`. السجلات المكتوبة بعد ذلك تحتوي على خصائصها الخاصة فقط.

### خطأ، تحذير، معلومات، تنقيح (error, warning, info, debug)

```
ماكرو خطأ[هذا، رسالة]؛
ماكرو خطأ[هذا، رسالة، خصائص]؛
```

(وكذلك `تحذير` و`معلومات` و`تنقيح`.) تكتب سجلًا بالمستوى المقابل.

* `رسالة` (`msg`) رسالة السجل.
* `خصائص` (`props`) خصائص السجل. راجع [الخصائص](#الخصائص).

## مـدخل (Entry)

```
صنف مـدخل {
    عملية هذا~init(مسجل: سند[مـسجل]، مستوى: صـحيح، رسالة: مـؤشر_محارف)؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: مـؤشر_محارف)؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: صـحيح[64])؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: عـائم[64])؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: ثـنائي)؛
    عملية هذا.حدد(مفتاح: مـؤشر_محارف، قيمة: سند[خـطأ])؛
    عملية هذا.أرسل()؛
}
```

<div dir=ltr>

```
class Entry {
    handler this~init(logger: ref[Logger], level: Int, msg: CharsPtr);
    handler this.set(key: CharsPtr, val: CharsPtr);
    handler this.set(key: CharsPtr, val: Int[64]);
    handler this.set(key: CharsPtr, val: Float[64]);
    handler this.set(key: CharsPtr, val: Bool);
    handler this.set(key: CharsPtr, val: ref[Error]);
    handler this.send();
}
```

</div>

سجل واحد. تنشئ ماكروات المستويات كائنًا منه وتضيف إليه الخصائص وترسله، لذا لا تحتاج عادةً لاستخدام هذا الصنف.
يمكنك استخدامه مباشرة لبناء سجل على عدة خطوات:

```
عرف مدخل: مـسجل.مـدخل(سجل، مـسجل.مـستوى.مـعلومات، "سجل يدوي")؛
مدخل.حدد("ن"، 42)؛
مدخل.أرسل()؛
```

لا يُطبع السجل إلا عند استدعاء `أرسل`. إنشاء `مـدخل` يبدأ السجل في المخزن المؤقت للمسجل، لذا أنهِ (`أرسل`) أي
مدخل قبل بدء مدخل آخر على نفس المسجل.

## صيغة المخرجات

### المفاتيح

يجب ألا يحتوي المفتاح على مسافات أو محارف تحكم أو `=` أو `"`. إذا احتوى على أي منها يُستبدل كل محرف منها بـ`_`.
المفتاح الفارغ يُطبع `_`.

### القيم

تُطبع القيمة النصية كما هي، إلا إذا كانت فارغة أو احتوت على مسافة أو `=` أو `"` أو `\` أو محرف تحكم. في هذه الحالة
توضع بين علامتي اقتباس، ويتم تهريب المحارف التي قد تكسر صيغة السطر الواحد، ولهذا فإن كل سجل يُكتب في سطر واحد فقط.

```
سجل.معلومات["اقتباس"، { المسار: "/tmp/my file"، فارغ: ""، قول: "قال \"مرحبا\"" }]؛
```

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00 level=info message=اقتباس المسار="/tmp/my file" فارغ="" قول="قال \"مرحبا\""
```

</div>
