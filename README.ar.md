# مـسجل (Logger)

<div dir=rtl>

[[English]](README.md)

مكتبة تسجيل للغة الأسس. تكتب كل سجل في سطر واحد بصيغة `logfmt`، وهي قائمة من أزواج `مفتاح=قيمة`:

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00 level=info user=Hisham age=22 message="logged in"
```

</div>

يبدأ كل سجل بمفتاحين:

* `time`: وقت كتابة السجل، بصيغة RFC 3339.
* `level`: مستوى السجل: `error` أو `warn` أو `info` أو `debug`.

وبعدهما تأتي المفاتيح التي تضيفها أنت بنفس ترتيب إضافتها.

تبقى أسماء المفاتيح `time` و`level` و`message` بالإنجليزية في المخرجات حتى عند استخدام الأسماء العربية للدالات، كي
تستطيع أدوات قراءة السجلات فهم السطر بنفس الطريقة أيًا كانت لغة الشيفرة.

## إضافة المكتبة للمشروع

اشمل المكتبة في مشروعك كالتالي:

```
اشمل "مـحا"؛
مـحا.اشمل_حزمة("Alusus/Logger@1.0"، "مـسجل.alusus")؛
```

<div dir=ltr>

```
import "Apm";
Apm.importPackage("Alusus/Logger@1.0");
```

</div>

## طريقة الاستخدام

ابدأ السجل باستدعاء دالة المستوى الذي تريده، ثم أضف الحقول بالتتابع، ثم استدع `أرسل` لطباعته:

```
مـسجل.معلومات()
    .نص("user"، "Hisham")
    .رقم("age"، 22)
    .ثنائي("admin"، 1)
    .رسالة("logged in")
    .أرسل()؛
```

<div dir=ltr>

```
Logger.info()
    .str("user", "hisham")
    .num("age", 22)
    .bool("admin", true)
    .msg("logged in")
    .send();
```

</div>

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00 level=info user=hisham age=22 admin=true message="logged in"
```

</div>

لا يُطبع السجل إلا عند استدعاء `أرسل`، فالسلسلة التي لا تنتهي بـ`أرسل` لا تطبع شيئًا.

## الدالات العمومية

### خطأ (error)

```
دالة خطأ(): مـدخل؛
```

<div dir=ltr>

```
func error(): Entry;
```

</div>

تبدأ سجلًا بالمستوى `level=error`.

### تحذير (warning)

```
دالة تحذير(): مـدخل؛
```

<div dir=ltr>

```
func warning(): Entry;
```

</div>

تبدأ سجلًا بالمستوى `level=warn`.

### معلومات (info)

```
دالة معلومات(): مـدخل؛
```

<div dir=ltr>

```
func info(): Entry;
```

</div>

تبدأ سجلًا بالمستوى `level=info`.

### تنقيح (debug)

```
دالة تنقيح(): مـدخل؛
```

<div dir=ltr>

```
func debug(): Entry;
```

</div>

تبدأ سجلًا بالمستوى `level=debug`.

### حدد_المستوى (setLevel)

```
دالة حدد_المستوى(مستوى: صـحيح): فـراغ؛
```

<div dir=ltr>

```
func setLevel(level: Int): Void;
```

</div>

تحدد أدنى مستوى يُطبع. السجلات التي مستواها أدنى من ذلك تُهمل، ولا تقوم استدعاءات حقولها بأي عمل. القيمة
الافتراضية هي `مـستوى.مـعلومات` (`Level.INFO`).

* `مستوى` (`level`) إحدى قيم [مـستوى](#مـستوى-level). أي قيمة أخرى تُتجاهل ويبقى المستوى الحالي كما هو.

```
مـسجل.حدد_المستوى(مـسجل.مـستوى.تـحذير)؛
مـسجل.معلومات().رسالة("لن يطبع").أرسل()؛
مـسجل.تحذير().رسالة("سيطبع").أرسل()؛
```

### استخدم_الوقت_المحلي (useLocalTime)

```
دالة استخدم_الوقت_المحلي(مفعل: ثـنائي): فـراغ؛
```

<div dir=ltr>

```
func useLocalTime(enabled: Bool): Void;
```

</div>

تحدد المنطقة الزمنية للمفتاح `time`. ينطبق هذا الإعداد على كل سجل يبدأ بعد الاستدعاء.

* `مفعل` (`enabled`) إذا كانت `1` يُطبع الوقت بالتوقيت المحلي مع فرق التوقيت الخاص به. وإذا كانت `0` (الافتراضي)
  يُطبع بالتوقيت العالمي UTC مع فرق التوقيت `+00:00`.

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00     // UTC (default)
time=2026-10-05T14:40:48+03:00     // local time
```

</div>

## مـستوى (Level)

```
وحدة مـستوى {
    عرف خـطأ: 40؛
    عرف تـحذير: 30؛
    عرف مـعلومات: 20؛
    عرف تـنقيح: 10؛
}
```

<div dir=ltr>

```
module Level {
    def ERROR: 40;
    def WARNING: 30;
    def INFO: 20;
    def DEBUG: 10;
}
```

</div>

مستويات السجل مرتبة من الأهم إلى الأقل أهمية. تُستخدم مع `حدد_المستوى`.

## مـدخل (Entry)

```
صنف مـدخل {
    عملية هذا.نص(مفتاح: مؤشر[مصفوفة[مـحرف]]، قيمة: مؤشر[مصفوفة[مـحرف]]): سند[مـدخل]؛
    عملية هذا.رقم(مفتاح: مؤشر[مصفوفة[مـحرف]]، قيمة: صـحيح[64]): سند[مـدخل]؛
    عملية هذا.رقم(مفتاح: مؤشر[مصفوفة[مـحرف]]، قيمة: عـائم[64]): سند[مـدخل]؛
    عملية هذا.ثنائي(مفتاح: مؤشر[مصفوفة[مـحرف]]، قيمة: ثـنائي): سند[مـدخل]؛
    عملية هذا.رسالة(رسالة: مؤشر[مصفوفة[مـحرف]]): سند[مـدخل]؛
    عملية هذا.أرسل(): سـندنا[خـطأ]؛
}
```

<div dir=ltr>

```
class Entry {
    handler this.str(key: ptr[array[Char]], val: ptr[array[Char]]): ref[Entry];
    handler this.num(key: ptr[array[Char]], val: Int[64]): ref[Entry];
    handler this.num(key: ptr[array[Char]], val: Float[64]): ref[Entry];
    handler this.bool(key: ptr[array[Char]], val: Bool): ref[Entry];
    handler this.msg(message: ptr[array[Char]]): ref[Entry];
    handler this.send(): SrdRef[Error];
}
```

</div>

سجل واحد. تحصل عليه من `خطأ` أو `تحذير` أو `معلومات` أو `تنقيح`، وهي التي تملأ المفتاحين `time` و`level`. كل دالة
حقل ترجع سندًا لنفس السجل، لذا يمكن استدعاء الدالات بالتتابع. صُمم السجل ليُستخدم داخل جملة واحدة تنتهي بـ`أرسل`.

### نص (str)

```
عملية هذا.نص(مفتاح: مؤشر[مصفوفة[مـحرف]]، قيمة: مؤشر[مصفوفة[مـحرف]]): سند[مـدخل]؛
```

<div dir=ltr>

```
handler this.str(key: ptr[array[Char]], val: ptr[array[Char]]): ref[Entry];
```

</div>

تضيف حقلًا نصيًا. راجع [القيم](#القيم) لمعرفة متى توضع القيمة بين علامتي اقتباس.

* `مفتاح` (`key`) اسم الحقل. راجع [المفاتيح](#المفاتيح).
* `قيمة` (`val`) قيمة الحقل.

### رقم (num)

```
عملية هذا.رقم(مفتاح: مؤشر[مصفوفة[مـحرف]]، قيمة: صـحيح[64]): سند[مـدخل]؛
عملية هذا.رقم(مفتاح: مؤشر[مصفوفة[مـحرف]]، قيمة: عـائم[64]): سند[مـدخل]؛
```

<div dir=ltr>

```
handler this.num(key: ptr[array[Char]], val: Int[64]): ref[Entry];
handler this.num(key: ptr[array[Char]], val: Float[64]): ref[Entry];
```

</div>

تضيف حقلًا رقميًا. تُطبع الأعداد الصحيحة كما هي، وتُطبع الأعداد العائمة بست خانات عشرية، فتُطبع `0.5` هكذا
`0.500000`.

* `مفتاح` (`key`) اسم الحقل. راجع [المفاتيح](#المفاتيح).
* `قيمة` (`val`) الرقم.

### ثنائي (bool)

```
عملية هذا.ثنائي(مفتاح: مؤشر[مصفوفة[مـحرف]]، قيمة: ثـنائي): سند[مـدخل]؛
```

<div dir=ltr>

```
handler this.bool(key: ptr[array[Char]], val: Bool): ref[Entry];
```

</div>

تضيف حقلًا قيمته `true` أو `false`.

* `مفتاح` (`key`) اسم الحقل. راجع [المفاتيح](#المفاتيح).
* `قيمة` (`val`) القيمة.

### رسالة (msg)

```
عملية هذا.رسالة(رسالة: مؤشر[مصفوفة[مـحرف]]): سند[مـدخل]؛
```

<div dir=ltr>

```
handler this.msg(message: ptr[array[Char]]): ref[Entry];
```

</div>

تضيف الرسالة الرئيسية للسجل تحت المفتاح `message`. وهي مماثلة لـ`نص("message"، رسالة)`.

### أرسل (send)

```
عملية هذا.أرسل(): سـندنا[خـطأ]؛
```

<div dir=ltr>

```
handler this.send(): SrdRef[Error];
```

</div>

تطبع السجل في سطر واحد. ترجع أول مشكلة وُجدت في مفاتيح السجل، أو سندًا فارغًا إذا كانت كل المفاتيح صحيحة. يُطبع
السجل في الحالتين. راجع [المفاتيح](#المفاتيح).

```
عرف خ: سـندنا[خـطأ] = مـسجل.معلومات().نص("user name"، "hisham").أرسل()؛
إذا !خ.أهو_عدم() طـرفية.اطبع("%s\n"، خ.هات_الرسالة().صوان)؛
```

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00 level=info user_name=hisham
Logger: invalid chars in key replaced by '_'
```

</div>

رمز الخطأ هو `LOGGER_INVALID_KEY`. إذا أُهمل السجل بسبب `حدد_المستوى` فلا تُفحص مفاتيحه وترجع `أرسل` سندًا فارغًا.

## صيغة المخرجات

### المفاتيح

يجب ألا يحتوي المفتاح على مسافات أو محارف تحكم أو `=` أو `"`. إذا احتوى على أي منها يُستبدل كل محرف منها بـ`_`
وترجع `أرسل` خطأً. المفتاح الفارغ يُطبع `_` وترجع `أرسل` خطأً كذلك.

### القيم

تُطبع القيمة النصية كما هي، إلا إذا كانت فارغة أو احتوت على مسافة أو `=` أو `"` أو `\` أو محرف تحكم. في هذه الحالة
توضع بين علامتي اقتباس، ويتم تهريب المحارف التي قد تكسر صيغة السطر الواحد، ولهذا فإن كل سجل يُكتب في سطر واحد فقط.

```
مـسجل.معلومات().نص("المسار"، "/tmp/my file").نص("فارغ"، "").نص("اقتباس"، "قال \"مرحبا\"").أرسل()؛
```

<div dir=ltr>

```
time=2026-10-05T11:40:48+00:00 level=info المسار="/tmp/my file" فارغ="" اقتباس="قال \"مرحبا\""
```

</div>
