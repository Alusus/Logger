# مُسجِّل Logger
[[English]](README.md)

مكتبة تسجيل للغة الأسس. تكتب كل سجل في سطر واحد بصيغة `logfmt`، وهي قائمة من أزواج `مفتاح=قيمة`:

```
time=2026-09-19T11:40:48+00:00 level=info message="Server started"
```

يحتوي كل سجل على ثلاثة مفاتيح:

* `time`: وقت كتابة السجل، بصيغة RFC 3339.
* `level`: مستوى السجل، ويحدده اسم الدالة التي تستدعيها: `error` أو `warn` أو `info` أو `debug`.
* `message`: النص الذي مررته للدالة.

## الدالات

تستلم كل دالة الرسالة كنص (`مؤشر[مصفوفة[مـحرف]]`) وتكتب سجلًا واحدًا. اسم الدالة التي تستدعيها يحدد قيمة المفتاح `level`،
والرسالة توضع دائمًا تحت المفتاح `message`.

### خطأ error

تكتب سجلًا بالمستوى `level=error`.

<div dir="rtl">

```
دالة خطأ (الرسالة: مؤشر[مصفوفة[محرف]]): فـراغ؛
```

</div>

```
function error(message: ptr[array[Char]]): Void;
```

### تحذير warning

تكتب سجلًا بالمستوى `level=warn`.

<div dir="rtl">

```

```

</div>

```

```

### معلومات info

## صيغة المخرجات

### الوقت (time)

الوقت بصيغة RFC 3339.

* **التوقيت العالمي UTC (الافتراضي):** يُكتب الوقت بالتوقيت العالمي مع فرق التوقيت `+00:00`.

  ```
  time=2026-09-19T11:40:48+00:00
  ```
